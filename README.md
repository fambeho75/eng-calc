# Engineering Calculations

A static web app (plain HTML/CSS/JS, no build step) with engineering calculators for durability, fatigue and materials.

Open `index.html` through any static web server, e.g. GitHub Pages. Works on desktop and phone, has dark/light mode, and can be added to the home screen.

## Notes on the spreadsheet

* **Notch factor at TWB:** α₁ uses the *stepped, bending* parameters but α₂ uses the *notched, bending* parameters. For a thickness step the
  consistent choice is stepped/bending for both. That gives α ≈ 1.656 instead of 1.585 at the default geometry. The app keeps the sheet values as the default and shows the alternative.
  In the photo of Tab. 5.3-1, the exponent on (a/ρ + t/ρ) is hard to read (−l or −1). There's a toggle for it.
* **Fatigue LCF:** the sheet multiplies k_sf onto the plastic term and ignores k_L and k_size. The app applies the factors to the elastic (strength) term.
  Both give the same result at the default k = 1.
* **Bolt torque:** the F_sp values are the Bosch Table 5 μ_G = 0.18 column. K_min = 0.158 is the μ_G = 0.10 / μ_K = 0.12 entry, while the stated range 0.10–0.18 would give 0.146.
  Taken together the result stays conservative. The values are kept as in the sheet.
* The Basquin coefficients in the HCF table equal σ_f′·2^b from the LCF table, so writing Basquin with N instead of 2N is consistent.
* The sheet's “Tunnplåt” chart leaves out VSCR420LA. The app includes it.

## Files

* `index.html`, `styles.css`, `app.js`: UI. `calc.js`: pure calculation functions. `data.js`: spreadsheet defaults. `chart.js`: small SVG charts.
* Formulas are rendered with native MathML, so there are no external dependencies.
* `tests/verify.js` + `tests/sheet-values.json`: verification against the spreadsheet (`node tests/verify.js`).
* Icons: `icon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-192/512.png`, `manifest.webmanifest`. They're generated by `src/gen_icons.py` (preview in `src/icon-preview.png`).
